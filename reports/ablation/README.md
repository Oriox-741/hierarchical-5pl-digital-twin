# Ablation Reports

This folder is reserved for ablation outputs. No ablation result should be claimed unless it is generated by scripts, reviewed, and committed intentionally with machine-readable metadata.

Expected ablation families:

- A0 neutral PPO evaluation.
- A1 route-candidate masking.
- A2 safety-projection diagnostic.
- A3 flat-vs-hierarchical comparison if predecessor outputs are available.
- A4 no-teacher-distillation training-time ablation, future work.
- A5 reward-blend sensitivity, future work.

The sanitized public repository may not include private checkpoints, full episode outputs, raw datasets, or registry artifacts required to run all experiments. Missing artifacts should be reported clearly rather than replaced with placeholder metrics.
