# Research Positioning

## Professor-facing Positioning

This repository presents a bounded, reproducible, simulator-grounded 5PL digital-twin research framework for hybrid continuous-discrete supply-chain orchestration. It combines a 73-feature operational observation, five bounded PPO continuous controls, and a hierarchical DQN tactical action surface with 48 structured actions for dispatch, route family, fleet mode, and replenishment decisions.

## What the Project Does

- Builds a Python-based 5PL simulation environment for controlled research experiments.
- Runs a `torch_joint` runtime path with PPO continuous controls and hierarchical DQN tactical actions.
- Documents simulator contracts, monitoring artifacts, benchmark summaries, and reproducibility boundaries.
- Provides public-safe scaffolding for future ablation and diagnostic studies.

## What the Project Does Not Claim

- No live enterprise deployment.
- No real-world company validation.
- No causal off-policy evaluation.
- No company-level economic optimality claim.
- No production readiness claim for a commercial TMS, WMS, ERP, or carrier marketplace.
- No worldwide state-of-the-art reinforcement-learning performance claim.
- No completed ablation results unless generated reports are present.

## Current Evidence

The main evidence is simulation-based. Public replay work is descriptive proxy evidence only and should be read as plausibility support, not as causal proof of real-world superiority. No private company data was used for final validation.

## Next Research Steps

- Run the planned ablation protocol when required private checkpoints and evaluation artifacts are available.
- Add company-calibrated validation only under a separate private-data governance process.
- Extend offline evaluation only with logged propensities, action context, and reward definitions sufficient for the target claim.
- Compare flat and hierarchical tactical policies only when predecessor outputs are available and clearly documented.
