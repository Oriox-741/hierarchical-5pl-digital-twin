# Public / Private Boundary

## Public GitHub Scope

The public GitHub repository may include sanitized source code, simulator and evaluation configs, model cards, reproducibility notes, advisor quick-read material, ablation protocol documentation, selected reports, and bounded claim documentation.

## Excluded from Public GitHub

The public repository must not include transcripts, CVs, personal contact details, student IDs, national IDs, raw private data, model binaries, checkpoints, baseline artifacts, databases, full application packages, or full thesis DOCX files containing personal, jury, or university metadata.

## Local Private Materials

Private application materials live outside the Git-tracked public repository at:

```text
../Egemen_GRA_Applications/
```

That local folder may contain CVs, research summaries, writing samples, transcripts, professor trackers, portal notes, recommender packets, and outreach templates. It should not be committed to GitHub.

## Claim Boundary

This project should be presented as simulator-grounded research evidence. Public replay artifacts are descriptive proxy evidence only. Live TMS/WMS/ERP integration, company-data validation, commercial production readiness, causal off-policy evaluation, and global SOTA claims are outside the public repository's evidence boundary.
